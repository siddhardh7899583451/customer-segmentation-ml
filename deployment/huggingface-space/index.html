Unsupervised Machine Learning & Architecture

This platform offers two complementary analytical modalities:

1. Standalone Browser Engine (Client-Side HTML/JS): Operates in offline, zero-backend environments. Reads customer or transaction CSVs, cleans invalid records, computes customer-level RFM metrics, and derives grounded personas from empirical quantiles.
2. Enterprise Python Machine Learning Pipeline (Python 3.12 CLI): Executes rigorous mathematical modeling:
  • Feature Engineering: Log transforms (\( \log(1+x) \)) and StandardScaler normalization to prevent scale dominance.
  • Model Comparison: Evaluates K-Means (k-means++), DBSCAN (density-based noise isolation), and Agglomerative Hierarchical clustering.
  • Mathematical Validation: Strict checks ensuring Silhouette, Davies-Bouldin, and Calinski-Harabasz metrics are computed only when \(2 \le k < N\).
  • Dimensionality Reduction: 2D PCA projection preserving maximum explained variance.

Dataset Provenance: Configured for the UCI Machine Learning Repository Online Retail Dataset (541,909 transactions across 4,372 customers). When run offline or in demonstration mode, mathematically generated synthetic demo cohorts are used and explicitly labeled.

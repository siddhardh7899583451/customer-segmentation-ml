# Customer Segmentation & Behavioral Analytics Platform

A high-performance, client-side, zero-backend interactive web application for RFM customer segmentation, cohort behavioral discovery, and marketing strategy recommendations.

## Features
- **Zero-Backend Execution:** Runs 100% in the browser using pure HTML5, modern CSS3, and vanilla JavaScript.
- **Client-Side RFM Engine:** Ingests raw transaction CSV logs or pre-aggregated RFM metrics.
- **Pure Canvas Visualizations:** Interactive charts for customer volume vs revenue contribution and behavioral scatter plots.
- **Grounded Persona Profiling:** Categorizes customer bases into distinct actionable personas (VIPs, Loyal Regulars, Recent Starters, At-Risk Churners).
- **Safe CSV Export:** Includes protection against CSV formula injection.
